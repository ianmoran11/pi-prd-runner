# PRD Review

Use this skill when reviewing a `pi-prd-runner` PRD implementation.

Rules:
- Review in a fresh context.
- Compare the diff to the PRD.
- Check every acceptance criterion.
- Decide `approved`, `changes_requested`, or `blocked`.
- Write the Markdown review report and structured JSON result.
- Do not modify implementation files.
