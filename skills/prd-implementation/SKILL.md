# PRD Implementation

Use this skill when implementing one `pi-prd-runner` PRD in a PRD-specific worktree.

Rules:
- Implement only the current PRD.
- Stay within included scope and avoid excluded scope.
- Run required checks when possible.
- Write implementation artifacts under the current attempt directory.
- Commit changes to the PRD branch when committing is available.
- Report incomplete work honestly.
