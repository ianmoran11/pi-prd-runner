# Implement PRD

Implement only the current PRD. Do not implement future PRDs or excluded scope.

Required behavior:
- Read the PRD and acceptance criteria.
- Make the smallest complete implementation for this PRD.
- Run required checks when possible.
- Write `implementation-summary.md`, `test-results.md`, `changed-files.md`, `diff.patch`, and `metadata.json`.
- Commit changes to the PRD branch when committing is available.
- Be explicit about incomplete work or known limitations.
